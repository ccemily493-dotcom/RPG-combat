# Universal RPG Engine v0.3.1 — Verification Checkpoint

## Result

Checkpoint passed before v0.4 work began. The repository validation at the checkpoint reported 157 passed tests, 0 failures, all 70 then-declared hard invariants passing, and all three engine goldens matching.

## Scheduler closure

- Dependencies no longer imply turn progression.
- `ZERO_TIME` condition/branch/state nodes iterate in the same session step with a configurable limit of 64.
- `ACTION`, `REACTION`, and `MOVEMENT` consume their matching economy. Dedicated movement capacity is optional and falls back to action capacity for backward compatibility.
- An action can unlock zero-time work and another action in the same turn when economy permits; the identical DAG spans turns when it does not.
- `PARTIAL` remains distinct. `ON_SUCCESS` is strict; `ON_PARTIAL` and `ON_PARTIAL_OR_BETTER` are explicit.
- Strategy execution becomes structurally `COMPLETED`; node and required/optional goal outcomes remain separate.
- Starting strategy/node order is canonicalized before temporal snapshot hashing, eliminating an incidental declaration-order dependency.

## Performance checkpoint

On Node v24.19.0/Windows x64, 40-run warm samples measured 3.812 ms/turn for the five-turn linear DAG and 3.093 ms/turn for a 20-turn session. Against the prior checked-in report these were approximately 25.1% and 33.6% faster respectively; the independent single-hit control varied upward by 19.6%, indicating ordinary run-to-run/system noise. No correctness shortcut was introduced.

## Ambiguities closed conservatively

- Newly created turn-duration effects use the resulting turn as their creation point so they cannot expire during the step that creates them.
- Multi-wave strategy actions call `resolveTurn` without advancing time, and the session performs one final atomic turn advancement/previous-turn commit.
- Public trace suppression removes nested turn traces but never changes internal mechanics or hashes.
